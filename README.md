# Discord 計算機機器人（/calculator）

一個基於 [discord.py](https://github.com/Rapptz/discord.py) 與 [SymPy](https://www.sympy.org/) 打造的
Discord 斜線指令計算機。支援純量、向量、矩陣運算，並且會把整個計算過程拆解成
一步一步的「詳細步驟」，用類 LaTeX 排版渲染成圖片呈現在 Discord 訊息中。

這個 repo 是從一個較大型的 Discord 機器人專案中獨立抽出來的最小可執行版本，
拿掉了原本綁定在那個機器人框架上的部分（封鎖名單、雙語指令、自訂冷卻/計數/
日誌系統），保留了計算機指令本身最核心也最有趣的部分。

![python](https://img.shields.io/badge/python-3.10%2B-blue)
![discord.py](https://img.shields.io/badge/discord.py-2.4%2B-5865F2)

## 功能特色

- **精確運算優先**：全程透過 SymPy 計算，能算就不用浮點數，分數 / 根號 /
  圓周率等都會保留成精確值，另外也提供一鍵切換的小數顯示模式。
- **純量／向量／矩陣三種模式**：模式可以手動指定，也可以讓機器人依算式內容
  （有沒有中括號）自動判斷。
- **詳細計算步驟**：把使用者輸入的算式逐步化簡，每一步都渲染成
  「上一步 = 這一步」的等式圖片，並用分頁按鈕瀏覽。
- **類 LaTeX 圖片渲染**：用 matplotlib 的 mathtext（Computer Modern 字型）
  畫出跟線上 LaTeX 產生器風格一致的算式圖片，矩陣則是逐格渲染再手繪中括號
  拼接而成，黑底白字適配 Discord 深色主題。
- **豐富的內建函數**：三角函數（含罕見的 haversine 系列）、雙曲函數、對數、
  組合數學（階乘、排列組合、重複組合）、統計函數（平均、中位數、變異數、
  相關係數、z-score...）、向量運算（內積、外積、投影、夾角...）、矩陣運算
  （行列式、逆矩陣、特徵值、RREF...）。
- **多層安全防護**：數字/次方上限檢查、AST 白名單驗證（避免屬性存取逃逸）、
  獨立子行程 + timeout 執行（避免惡意輸入卡死整個機器人）。

## 系統需求

- Python 3.10 以上
- 一個 Discord Bot 應用程式與 Token（[Discord Developer Portal](https://discord.com/developers/applications)）

## 安裝

```bash
git clone <this-repo-url>
cd discord-calculator-bot
pip install -r requirements.txt
```

## 設定

1. 複製 `.env.example` 為 `.env`：

   ```bash
   cp .env.example .env
   ```

2. 打開 `.env`，填入你的 Bot Token：

   ```env
   DISCORD_BOT_TOKEN=你的token
   GUILD_ID=          # 選填，開發測試用，見下方說明
   ```

   - `DISCORD_BOT_TOKEN`：必填。
   - `GUILD_ID`：選填。設定後指令只會同步到這個伺服器 ID，幾乎立即生效，
     很適合開發測試；留空的話會同步成**全域指令**，最多可能要等一小時
     才會在所有伺服器出現。

3. 到 Discord Developer Portal 的 **OAuth2 → URL Generator**，勾選
   `bot` 與 `applications.commands` 這兩個 scope，`bot permissions` 至少
   需要「傳送訊息」「附加檔案」「嵌入連結」，用產生的邀請連結把機器人加入
   你的伺服器。這個指令不需要任何 Privileged Intents。

## 執行

```bash
python bot.py
```

看到終端機印出 `已登入：<機器人名稱>` 就代表啟動成功，之後就可以在
Discord 裡輸入 `/calculator`（中文介面顯示為 `/計算機`）。

## 指令用法

```
/calculator 函式:<要計算的算式> [角度單位] [模式]
```

| 參數     | 必填 | 說明 |
|----------|------|------|
| 函式     | ✅   | 要計算的算式，例如 `sin(30)+2^2`、`[1,2,3]+[4,5,6]`、`[[1,2],[3,4]].det()` |
| 角度單位 | ❌   | `弧度`（預設）或 `角度`，只影響三角函數的輸入/輸出 |
| 模式     | ❌   | `純量` / `向量` / `矩陣`，不填會依算式內容自動判斷（有中括號會自動視為向量或矩陣） |

送出指令後，機器人會回覆一則訊息，上面有兩個頁籤：

- **計算結果**：算式與結果的圖片，若結果含分數/無理數，會多一顆
  「顯示小數」按鈕可以切換精確值／小數（最多到小數第 12 位）。
- **詳細步驟**：把計算過程拆解成一步一步的等式圖片，每頁顯示 3 步，
  可用 `⏪ 🔙 🔜 ⏩` 按鈕換頁。

### 範例

```
/calculator 函式:log10(100)+5*5
/calculator 函式:sin(30) 角度單位:角度
/calculator 函式:[1,2,3].norm()
/calculator 函式:[[1,2],[3,4]].det()
/calculator 函式:mean(1,2,3,4,5)
```

# 函數介紹

## 一、基本介紹

一個支援【純量】【向量】【矩陣】運算，並可顯示詳細計算步驟（含 LaTeX 圖片）的數學計算機指令。

| 項目       | 說明                                                             |
| -------- | -------------------------------------------------------------- |
| 指令名稱     | `/calculator`（英文）／`/計算機`（中文）                                   |
| 運算引擎     | SymPy（精確運算優先，必要時才轉換為浮點數）                                       |
| 運算模式     | 純量（預設）／向量／矩陣，未指定時依算式內容自動偵測（偵測到中括號 `[]` 自動切換為向量或矩陣）             |
| 角度單位     | 弧度 rad（預設）／傳統角度 360°，可用選項切換                                    |
| 結果顯示     | Discord Components V2 頁籤介面：「計算結果」／「詳細步驟」，步驟每頁顯示 3 步並附 LaTeX 圖片 |
| 精確值／小數切換 | 結果為分數、無理數等「有小數版本」時，可用按鈕切換顯示小數（最多 12 位，超過以 `...` 表示）            |

## 二、安全防護機制

為避免使用者輸入造成機器人卡死或記憶體爆炸，內建多道防線：

| 限制項目                                   | 上限        | 說明                                     |
| -------------------------------------- | --------- | -------------------------------------- |
| 數字輸入絕對值                                | 1,000,000 | 超過會直接擋下，不進入運算                          |
| 次方數（`**` / `^`）                        | 1,000     | 單一次方運算的指數上限                            |
| 連續冪次（冪塔）                               | 禁止        | 例如 `9**9**9` 會被擋下，需用括號拆開，如 `9**(9**2)` |
| `factorial` / `comb` / `perm` / `H` 引數 | 500       | 避免過大的組合數運算                             |
| 向量／矩陣單一維度                              | 12        | 列或欄最多 12 個元素                           |
| 運算逾時                                   | 6 秒       | 使用獨立子行程執行，逾時強制終止，不影響主程式                |
| AST 白名單驗證                              | —         | 禁止屬性存取逃逸，只允許白名單內的方法                    |

## 三、運算模式

| 模式  | 代碼       | 觸發方式                            |
| --- | -------- | ------------------------------- |
| 純量  | `scalar` | 預設模式；輸入不含中括號時使用                 |
| 向量  | `vector` | 輸入含 `[...]`（非巢狀）時自動切換，或手動指定     |
| 矩陣  | `matrix` | 輸入含 `[[...]]`（巢狀中括號）時自動切換，或手動指定 |

## 四、語法與輸入格式支援

| 功能        | 範例                                         | 說明                                                         |
| --------- | ------------------------------------------ | ---------------------------------------------------------- |
| 基本運算子     | `+` `-` `*`（`×`）`/`（`÷`）`//` `%` `**`（`^`） | 全形符號 `×` `÷` 會自動轉換                                         |
| 上標次方      | `2³` = `2^3` = `2**3`                      | 支援 `⁰¹²³⁴⁵⁶⁷⁸⁹` 上標數字                                       |
| 取餘數       | `10 mod 3`                                 | 等同 `10 % 3`                                                |
| 隱式乘法（貼括號） | `4(2)`、`(2)4` = `8`                        | 大中小括號皆可；括號前為函數名稱時不適用（例如 `log10(100)` 仍是 `log10(100)` 而非乘法） |
| 絕對值簡寫     | `\|x\|`、支援巢狀 `\|\|x\|+1\|`                 | 自動轉換為 `Abs(x)`                                             |
| 開根號符號     | `√9`、`√(9+16)`                             | 自動轉換為 `sqrt(...)`                                          |
| 階乘符號      | `5!`、`(1+2)!`                              | 自動轉換為 `factorial(...)`                                     |
| 中／大括號     | `[ ]`、`{ }`                                | 純量模式下視為一般小括號；向量／矩陣模式下 `[ ]` 用於建構向量或矩陣，不可互換                 |
| 十六進位      | `0x1A`                                     | 支援 `AaCcDdFf` 字元，自動轉為十進位                                   |
| 千分位逗號     | `12,345`                                   | 自動移除逗號                                                     |
| 循環小數判定    | `0.9999999999999`（13 位以上連續 9）              | 直接視為 `1`                                                   |
| 變數佔位符     | 算式：`1+?+?+?+?+?` 替換值：`1,4,5,1,4`           | `?` 依序被替換值取代，組成 `1+1+4+5+1+4`                              |
| 常數別名      | `π`、`𝝅`、`τ`                               | 分別對應 `pi`、`pi`、`tau`                                       |
| 大數自動轉換顯示  | 超過 2³¹ 的整數結果                               | 不再強制輸出整數，改用小數或科學記號表示                                       |
| 小數精確度     | 最多顯示到小數點後 12 位                             | 超過位數以 `...` 表示還有更多位數                                       |

## 專案結構

```
discord-calculator-bot/
├── bot.py                 # 獨立執行的進入點
├── requirements.txt
├── .env.example
└── calculator/
    ├── __init__.py
    ├── command.py          # 斜線指令本體（Cog）
    ├── _engine.py          # 數學運算核心（SymPy 解析、安全限制、逐步化簡）
    ├── _render.py          # 把算式渲染成 LaTeX 風格的 PNG 圖片
    └── _view.py            # Discord Components V2 結果顯示介面
```

## 已知限制

- matplotlib 的 mathtext（非 `usetex` 模式）只支援一般數學排版的子集，
  部分較複雜的 LaTeX 語法（例如某些巢狀環境）可能顯示不如預期，
  遇到解析失敗時會自動退回純文字顯示，不會讓指令直接失敗。
- 這是把使用者輸入字串丟給 SymPy 表達式解析器處理，雖然有 AST 白名單、
  數字/次方上限、獨立子行程 + timeout 等多層防護，但無法做到 100%
  資安等級的沙盒隔離，正式環境建議額外搭配限制記憶體、停用網路的容器
  一起使用。
- 矩陣/向量單一維度上限為 12（可在 `_engine.py` 的 `MAX_MATRIX_DIM`
  調整），避免特徵值分解等運算在大矩陣上耗時過久。
